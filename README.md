# 📚 Programming Studies & Academic Exercises

This repository gathers exercises, practical challenges, and algorithms developed throughout my academic journey at **Univesp**, my technical degree at **ETEC**, and additional courses/bootcamps.

The main objective is to consolidate fundamentals of **Programming Logic**, **Data Structures**, **Object-Oriented Programming (OOP)**, and coding best practices.

---

## 🛠️ Technologies & Concepts

- **Languages:** Java, JavaScript.
- **Concepts:** Algorithms, Data Structures (Stacks, Queues, Lists, Trees), OOP (Encapsulation, Inheritance, Polymorphism, Abstraction).
- **Tools & IDEs:** VS Code, IntelliJ IDEA, Git, and GitHub.
